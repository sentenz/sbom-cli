# SBOM CLI

Use the SBOM CLI to upload CycloneDX bills of materials to Dependency-Track and manage projects by name and version.

- [Upload methods](upload-methods.md) explains how to upload from the CLI or a container.
- [REST API](rest-api.md) describes the underlying HTTP requests.
- [Configuration precedence](order-of-precedence.md) explains how the CLI resolves settings.
- [Troubleshooting](troubleshoot.md) covers authentication, connectivity, and file permissions.

The API Reference documents the Python client and the exceptions callers can catch.
